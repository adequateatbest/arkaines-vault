I'm building a Diablo 1 save editor. I've attached two files:

diablo1-save-editor-spec.md — a spec covering everything reverse-engineered from a real save file this session: the MPQ container format, the game's custom save encryption, both player-data struct layouts (the compact hero format and the raw game format, and why you need both), item identity tables, and a suggested architecture.
diablo1-save-editor-starter.zip — working reference code from that same session, verified against a real save file. Contains:
reference_code/ — a tested implementation of the save cipher, the PKWARE decompressor, the safe MPQ-patching strategy (important: a naive full-archive-rewrite approach crashes the real game even though it's spec-legal MPQ — this code avoids that), and struct parsers for both save formats.
reference_source/ — relevant excerpts from the devilution decompilation (item logic, save/load code, struct/enum definitions) for cross-referencing exact game behavior.
README.md — explains what's in each file, what's verified vs. still needs building, and a suggested build order.
